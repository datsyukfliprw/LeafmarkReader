# Deployment

Leafmark is designed to run as one local web service. The production Fastify process serves `/api/*` and the built PWA from `apps/web/dist`, so an iPad only needs one home-server URL.

## First install

1. Install Node.js 22+ and build tools required by `better-sqlite3`.
2. Copy this repository to the home server and run `npm install`.
3. Copy `.env.example` to `.env` and change `COOKIE_SECRET`, `PARENT_PIN`, and child PINs. Set `APP_ORIGIN` to the exact URL the iPad will use, for example `http://192.168.1.82:8787` or your local HTTPS URL.
4. Confirm the local OpenAI-compatible endpoint and Bonsai model name in `.env`.
5. Run `npm run db:migrate`, `npm run build`, and then `NODE_ENV=production npm start`.
6. Open the server URL in Safari on the iPad, use Share → Add to Home Screen, and launch Leafmark from its Home Screen icon.

For long-running deployment, adapt `deploy/leafmark.service` to your paths. Run the service as a dedicated unprivileged account. If exposing Leafmark beyond a trusted LAN, place it behind HTTPS and a properly configured reverse proxy. The intended default is LAN-only.

## Updating

Stop the service, run `npm run backup`, update the repository, run `npm install`, `npm run db:migrate`, `npm run build`, and restart. Schema migrations are additive and preserve student work.


## Render.com

The repository root contains `render.yaml`. Create a Blueprint in Render from this repository. The Blueprint provisions a Starter web service and a 1 GB persistent disk mounted at `/var/data`; SQLite is stored at `/var/data/leafmark.sqlite`. A persistent disk is required because Render's normal filesystem is ephemeral.

Set `PARENT_PIN` and `CHILDREN` in the Blueprint creation flow. `COOKIE_SECRET` is generated by Render. The Render start command automatically passes `RENDER_EXTERNAL_URL` through as `APP_ORIGIN`, so you do not need to know the generated hostname in advance. If you add a custom domain, set `APP_ORIGIN=https://your-domain.example` and redeploy.

Do not move migrations to Render's pre-deploy command: pre-deploy runs on separate compute and cannot access the service's persistent disk. Leafmark runs its migrations at server startup before listening.

A cloud Render service cannot directly reach a Bonsai server listening on `127.0.0.1` on your home machine. Without a remotely reachable OpenAI-compatible endpoint, Leafmark uses its deterministic safe fallbacks. To enable model-backed phrasing/evaluation, set `LOCAL_AI_BASE_URL`, `LOCAL_AI_API_KEY`, and optionally `LOCAL_AI_MODEL` to an endpoint Render can reach.
